## 专线带宽价格由什么决定？

先把答案放在前面：影响专线带宽价格的核心变量有五个——带宽大小、城市级别、接入层级、路由方式、SLA 服务等级。带宽只是其中之一，剩下每一项都能让同样的 10M 差出几千块。

以运营商互联网专线为例，逐项拆开：

- **带宽**：速率越高月租越贵，但不是线性增长——10M 到 100M 价格翻十倍左右，100M 往上每升一档都是一个新台阶。
- **城市级别**：北京、上海、广州、深圳这类一线城市最贵，其他城市依次递减。
- **接入层级**：同样 10M，接在城域网汇聚层比接在接入层贵约 25%。
- **路由方式**：普通静态路由和 BGP 路由接入是两张价目表。
- **SLA 等级**：要更高等级的保障协议，月租在标准价基础上上浮 10%–25%。

还有两个容易忽略的小头：开户费和 IP 地址费。运营商专线一般附带少量 IP，超出部分按个收月租。

## 运营商企业专线：10M 月租五千起步，10G 是另一个世界

按备案资费，10M 专线在一类城市接入层的月租是 ¥5,180，这就是企业互联网专线的起步量级；往上到 10G，一个月要四百多万。下面这份是联通互联网专线接入的备案资费标准（较早公开的版本，用来判断量级足够了），注意这些都是挂牌价，后面会讲怎么谈。

| 速率 | 汇聚层月租（一类城市） | 接入层月租（一类城市） | 附带 IP 数 |
| --- | --- | --- | --- |
| 10M | ¥6,480 | ¥5,180 | 2 |
| 45M | ¥26,800 | ¥21,500 | 2 |
| 100M | ¥57,200 | ¥45,700 | 4 |
| 200M | ¥109,300 | ¥87,400 | 8 |
| 500M | ¥265,700 | ¥212,600 | 16 |
| 1G | ¥506,200 | ¥405,000 | 64 |
| 10G | ¥4,455,000 | ¥3,564,000 | 256 |

几个直接影响预算的细节：

1. **开户费 100 元**，一次性。
2. **城市分级降档**：天津、成都、南京等 30 个二类城市比一类城市便宜约 5%，其他城市再低一档——10M 接入层最低只要 ¥4,400/月。
3. **BGP 路由更贵**：10M 全穿透 BGP 接入汇聚层 ¥9,950/月，比静态路由贵一半以上。这是给需要广播自己 IP 段的用户准备的，普通企业用不上。
4. **SLA 上浮**：紫金服务 +10%，黄金 +20%，白金 +25%，由买卖双方协商确定。
5. **IP 超量按 ¥50/月/个** 收取。
6. **最关键的一条藏在资费注释里**：各省级公司可以在标准资费基础上最大下浮 15%。表里的数字是挂牌价，实际询价时这个空间是真实存在的。

排期也要算进项目时间：带宽 200M 以上、自带 16 个 C 类 IP 以上，以及所有 BGP 接入申请，都要报运营商集团层面审批，周期比装一条普通宽带长得多。

## 云厂商专线：阿里云的账单只是其中一半

企业上云要用专线连本地机房时，找云厂商买的是“接入能力”，线路本身还是租运营商的。以阿里云高速通道为例，账单分这么几块：

| 带宽规格 | 一次性接入费 | 资源占用费（预付费） |
| --- | --- | --- |
| 1Gbps | $1,500 | $85/月 |
| 10Gbps | $1,500 | $720/月 |
| 40Gbps | $1,500 | $2,450/月 |
| 100Gbps | $1,500 | $5,200/月 |

预算只按这张表做，实际账单往往对不上。原因很简单：**专线租用费由运营商或合作伙伴单独收取，按带宽大小和距离计价**，云厂商那部分只是你占用它机房、设备、光缆资源的钱。机房楼内如果要布线，楼内线缆租赁费也是按运营商报价另算。

做预算的正确姿势是把两段问全：云厂商的资源占用费加上运营商段的租用费，加起来才是这条专线的真实月成本。京东云等其他云厂商的专线服务也是类似的计费结构，具体金额各有差异，问的时候直接要“全链路报价”最省事。

## 跨境专线：IEPL 和精品公网线路不是一回事

个人用户搜“专线带宽价格”，大多数时候想要的是第三类：一条从国内到海外的稳定线路，用来远程办公、访问海外业务。这个市场的报价逻辑和前两者完全不同，坑也最多。

相关社区讨论里反复出现的一组对比，是 IEPL 专线和 CMI、AS9929、GIA 这类“精品公网”线路。结论其实很朴素：**只要 IEPL 没有超卖，线路品质就高于任何精品公网线路**——公网再怎么优化也是共享的，比不过一根独享的光纤。

问题出在“超卖”两个字上。同一条物理线路，服务方卖给 1 个人和卖给 50 个人，成本一样，体验天差地别。这就是为什么同样挂着“专线”名头的服务，价格能差出好几倍：便宜得离谱的，往往在超卖上做了文章；贵的，买的是独享。顺带一提，商用宽带在这个对比里也不便宜，而且它和精品公网一样属于共享线路，高峰期表现没法和独享专线比。
